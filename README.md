# Supplementary Materials

This repository contains the code and processed results accompanying the submitted manuscript.

## Repository Structure
```
.
├── code/
│   ├── analysis/
│   │   ├── analyze_predictions.Rmd       # Analyze prediction results
│   │   ├── analyze_real_data.qmd         # Analyze results using real-world data
│   │   └── analyze_reinforcement.Rmd     # Analyze the reinforcement effect
│   ├── data_generation/
│   │   ├── data_sim.Rmd                  # Generate simulated data
│   │   ├── synthesize_data.Rmd           # Create synthetic data from simulations
│   │   └── synthesize_real_data.qmd      # Create synthetic data from real-world data
│   ├── predictions/
│   │   ├── pred_on_bnsyn.Rmd             # Predict using Bayesian network synthetic data
│   │   ├── pred_on_cartsyn.Rmd           # Predict using CART synthetic data
│   │   ├── pred_on_parmsyn.Rmd           # Predict using parametric synthetic data
│   │   ├── pred_on_sim.Rmd               # Predict using simulated data
│   │   ├── pred_on_svmsyn.Rmd            # Predict using SVM synthetic data
│   │   └── pred_real_data.qmd            # Predict using real-world data
│   ├── prediction.R                      # Prediction functions
│   ├── simulation.R                      # Simulation functions
│   ├── synthesis.R                       # Synthetic data generation functions
│   └── synthesis_real_data.R             # Synthesis functions for real-world data
├── results/
│   ├── additional_materials/             # Supplementary analysis outputs
│   └── figures/                          # Figures generated by the analyses
├── .gitignore
├── LICENSE
└── README.md
```


## Real-World Data

The empirical applications use publicly available datasets from the UCI Machine Learning Repository:

- Adult
- Bank Marketing
- Bike Sharing
- German Credit

The datasets are not redistributed in this repository and can be obtained from their original sources.

## Software

The analyses are implemented in R. The main packages used include:

```text
MASS
caret
rpart
glmnet
synthpop
e1071
bnlearn
kernlab
FNN
future
furrr
ggplot2
dplyr
tidyr
purrr
```

Some steps are parallelized. The number of workers can be adjusted in the corresponding R Markdown files.
